Donqui-ocuKeyboardPatch

Gives you the ability to add hover descriptions and color-coding to keys - configured in OCU keyboard studio. 
Requires OCU and MO2 Root Builder.

1. Drop it into MO2 right below OCU.
2. Copy the original OCU's opencomposite.ini into this mod's root folder if you want your settings to carry over. 
3. Open this mod's folder and run Donqui-ocuKeyboardPatch.exe. Open Keyboard Studio, edit, and Save.
4. Launch Skyrim VR and use your usual OCU keyboard shortcut.
